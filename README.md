# Биография — локальное Windows-приложение

Программа преобразует русскоязычное интервью в биографический DOCX и две транскрипции. Аудио и сведения обрабатываются на компьютере пользователя. Полученные документы требуют проверки человеком.

## Как получить программу

Готовые установщики находятся в [Releases](https://github.com/Isupov-Ilya/Documents/releases). Выпуск появляется только после сборки и проверки установленного EXE на Windows; [текущая проверка — во вкладке Actions](https://github.com/Isupov-Ilya/Documents/actions).

1. Скачайте **Biography-Setup-Windows-x64.exe** из последнего проверенного выпуска.
2. Запустите установщик. Отдельно устанавливать Python, Git, FFmpeg или библиотеки не нужно.
3. В программе откройте «Настройки» и выберите папку данных.
4. Нажмите «Загрузить модели». Первичная загрузка около **3 ГБ** требует интернета. Файлы проверяются по контрольным суммам; загрузку можно приостановить и продолжить.
5. После подготовки обработка работает **без интернета**. Аудио не передаётся в облачный ИИ.

Целевая конфигурация: Windows 11 x64, **16 ГБ RAM**, не менее 12 ГБ свободного места. Проверенная сборка использует CPU. RTX/CUDA в неё не включены. Обработка может занимать значительно больше времени, чем длительность записи; оценки для конкретного компьютера ещё нужно измерить.

Для компьютера без сети заранее подготовьте папку данных на другом компьютере, перенесите её вместе с установщиком и выберите в настройках. Для переноса исходников используйте [Download ZIP](https://github.com/Isupov-Ilya/Documents/archive/refs/heads/main.zip). Исходный ZIP не содержит многогигабайтные модели и не заменяет установщик.

Подробно: [установка, перенос моделей и сохранение результатов](docs/offline-windows.ru.md).

## Работа с интервью

- Выберите один M4A, MP3 или WAV и число участников: два или три.
- Выберите стандартную структуру либо импортируйте DOCX-образец и один раз сопоставьте поля.
- Нажмите «Начать обработку». Если программа не уверена в ролях, она сохранит транскрипцию и предложит уточнение.
- Проверьте текст по аудио, людей и факты. Исправления сохраняются отдельными версиями.
- Создайте DOCX. Отсутствующие сведения, противоречия и сомнительные утверждения выделяются.
- История позволяет открыть задание, найти его по ФИО/дате и продолжить работу после остановки.

Исходное аудио не изменяется. Для каждой попытки создаётся новая папка. Завершённые аудиоэтапы можно использовать повторно только после сверки исходных данных, настроек и контрольных сумм артефактов. Изменённая транскрипция запускает новый анализ. В профилях шаблонов сохраняются версии, а постоянный текст переносится только после явного подтверждения отсутствия чужих персональных сведений.

Импорт образца поддерживает абзацы, таблицы и основное оформление. Изображения, фигуры, сложные поля Word и колонтитулы автоматически не переносятся. Очищенная транскрипция выполняет консервативную нормализацию; полноценная литературная редактура не заявляется.

## Проверки и ограничения качества

В выпуск прикладывается Windows-validation.zip: отчёт фактического прогона EXE с моделями, положительный контроль сети и повторный запуск с исходящими Windows Firewall-правилами Block, проверка работы без Python в PATH, русских путей, M4A, DOCX и штатного Windows-окна.

Это исследовательская предварительная версия. Короткий синтетический тест не подтверждает статистическую полноту на реальных часовых интервью. Распознавание ошибается в именах и названиях; точность привязки людей и интерпретации сведений не гарантируется. Документы обязательно проверяются человеком. `reported` означает «сказано в интервью», а не «независимо проверено».

## Для разработчика

```bash
python -m venv .venv
python -m pip install -e ".[test,gui,asr,onnx-diarization,llm]" onnx==1.23.2
python -m pytest -q
python -m biography gui
```

Для Windows-сборки используйте `.github/workflows/windows-release.yml` либо штатные scripts/prepare_windows_tools.py, scripts/build_windows.py и Inno Setup. Linux PyInstaller не создаёт настоящий Windows EXE. Все подготовительные загрузки отделены от рабочего офлайн-конвейера. Веса и личные интервью исключены из Git.
