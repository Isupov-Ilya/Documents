# Исторический отчёт первоначального прототипа

Этот отчёт относится к первому Linux-прототипу, до восстановления доступа к моделям и создания настольного приложения. Указанные ниже ограничения сети, число тестов и список невыполненных проверок описывают тот запуск, а не текущее состояние проекта. Текущие фактические Windows-отчёты приложены к [проверенным выпускам](https://github.com/Isupov-Ilya/Documents/releases); методика описана в [windows-product.ru.md](windows-product.ru.md). Инструкция обычному пользователю: [установка и перенос](offline-windows.ru.md).

Платформа: Linux-6.18.57-x86_64-with-glibc2.41, Python 3.12.14. Это облачный Linux, не Windows.

## Выполнено

- Установка пакета в отдельное venv без системных site-packages; Pydantic 2.14.3, psutil 7.2.2.
- pytest: **20 passed**, без пропусков. Проверены схемы, аудиодекодирование реальным FFmpeg, неизменность исходника, повреждённый файл, привязка голосов, подтверждение ролей, цитаты, неизвестные лица, конфликты, приблизительные даты, дубликаты, запрет сети, ошибки/остановка, защита результатов и сквозной конвейер с тестовыми адаптерами.
- Ruff: All checks passed. git diff --check: без ошибок.
- Импорт faster-whisper 1.2.1 и CTranslate2 4.9.0 в настоящем окружении; поддерживаемые CPU-типы: float32, int16, int8, int8_float32. Проверен отказ при отсутствующей локальной модели без сетевой подстановки.
- Экспорт JSON Schema; CLI demo и check.

- Неуверенных реплик: 2; фактов для проверки: 4.
- Время: 0.0189 с.

## Не выполнено и почему

Hugging Face в текущем сетевом профиле отвечает 403 на HTTPS CONNECT. Веса ASR/диаризации/LLM не загружены. Сохранён черновик добавления huggingface.co, cdn-lfs.huggingface.co, cdn-lfs.hf.co, cas-bridge.xethub.hf.co, cas-server.xethub.hf.co и transfer.xethub.hf.co. Сохранение не применяет настройки и не публикует среду.

Реальные распознавание, диаризация, LLM-извлечение, WER/DER, полнота, точность привязки фактов, 60 минут, CPU/GPU и Windows пока **не проверены**. Критические гипотезы H-02, H-04, H-05, H-08 остаются открытыми. Итоговая программа по всему ТЗ ещё не готова к приёмке.

После применения сетевых настроек: загрузить небольшие доверенные модели и синтетическое/размеченное русское аудио, провести реальный CPU-smoke-тест, затем сравнить варианты на независимом наборе. Проверить лицензии и происхождение весов до загрузки. Не переходить к GUI/DOCX как будто качество уже доказано.
