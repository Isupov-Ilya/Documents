# Установка и перенос на Windows

## Установка готовой программы

1. Откройте [проверенные выпуски](https://github.com/Isupov-Ilya/Documents/releases) и скачайте `Biography-Setup-Windows-x64.exe`.
2. Запустите установщик и затем ярлык «Биография». Python, Git, FFmpeg и средства разработки устанавливать отдельно не нужно.
3. Во вкладке «Подготовка и настройки» выберите папку данных на диске с достаточным свободным местом. Нажмите «Подготовить локальные модели» и дождитесь завершения.
4. Первичная загрузка составляет около 5,2 ГБ; на диске нужно не менее 12 ГБ для программы, моделей и промежуточных файлов. Для больших интервью и нескольких проектов оставьте дополнительное место. Загрузку можно приостановить и продолжить. Контрольные суммы проверяются автоматически.
5. После подготовки отключите интернет, выберите M4A, MP3 или WAV во вкладке интервью и начните обработку. Модели и аудио обрабатываются локально. Уточните роли, если программа запросит это, и проверьте сведения перед использованием DOCX.

Целевой компьютер: Windows 11 x64, 16 ГБ RAM. Проверяемая поставка использует CPU. Для RTX/CUDA нет подтверждённой сборки; видеокарта не требуется для этого профиля. Программа не подписана сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen. Не отключайте защиту Windows целиком.

## Перенос на компьютер без интернета

1. На Windows-компьютере с интернетом установите программу и полностью подготовьте модели указанным выше способом.
2. Закройте программу. Скопируйте **всю выбранную папку данных**, а не только `settings.json`, на внешний диск вместе с установщиком. По умолчанию данные находятся в `%LOCALAPPDATA%\Biography`. Выбранный путь виден в настройках.
3. На целевом компьютере установите EXE и скопируйте папку данных на локальный диск. В «Подготовка и настройки» нажмите «Выбрать папку данных и моделей» и укажите перенесённую папку. Стандартная подготовка сохраняет переносимые относительные пути моделей.
4. Проверьте готовность и обработайте небольшую запись без сети. Если вы вручную выбирали нестандартные модели по абсолютным путям, повторно укажите их расположение в расширенных настройках.

Папка данных может содержать личные интервью и документы. Для переноса только моделей подготовьте отдельную пустую папку данных и не добавляйте туда интервью.

## Сохранение проекта и результатов

- Готовая программа: сохраните установщик, файл `SHA256SUMS.txt` и подготовленную папку данных. Контрольную сумму установщика можно проверить в PowerShell: `Get-FileHash .\Biography-Setup-Windows-x64.exe -Algorithm SHA256`.
- Исходники: [скачайте ZIP из GitHub](https://github.com/Isupov-Ilya/Documents/archive/refs/heads/main.zip) и распакуйте. Git устанавливать не обязательно. Архив не содержит моделей и не заменяет установщик.
- Интервью: сохраняйте папку результата целиком вместе с исходным аудио. Три DOCX можно скопировать отдельно для чтения и редактирования, но для продолжения работы нужны JSON-файлы проекта. Список заданий доступен в «Истории», чужую сохранённую папку можно открыть оттуда же.

## Что именно проверяет выпуск

`Windows-validation.zip` содержит фактический прогон установленного EXE с локальными моделями, запретом исходящей сети через Windows Firewall, Python вне PATH, русскими путями и M4A, а также проверку трёх DOCX и штатного окна Windows. Часовая проверка, когда приложена отдельно, использует повтор синтетического интервью и проверяет устойчивость обработки большого файла. Она не измеряет смысловую полноту на независимом часовом интервью. Проверка человеком обязательна.

Сборка из исходников предназначена для разработчика: см. [README](../README.md) и [описание Windows-сборки](windows-product.ru.md). Обычному пользователю wheelhouse и компилятор не нужны.
