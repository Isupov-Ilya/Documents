# Архитектура

Модульный локальный конвейер без сервера и Docker:

```text
cli.py → pipeline.py
            ├─ audio.py          FFprobe / FFmpeg, PCM mono 16 kHz
            ├─ backends.py       faster-whisper / pyannote / llama.cpp
            ├─ alignment.py      интервалы → голоса → реплики
            ├─ intelligence.py   роли, люди, факты, источники
            ├─ schemas.py        Pydantic / JSON Schema 1.0
            ├─ io.py             SHA-256, атомарный JSON
            └─ offline.py        offline-переменные, запрет socket.connect
```

Тяжёлые зависимости импортируются только в настоящем режиме. Модели аудио загружаются последовательно и освобождаются до LLM. Поток измеряет RSS процесса и потомков каждые 50 мс; время сохраняется по этапам. VRAM и кратковременные пики не измеряются.

Whisper выдаёт временные метки слов. Назначение голоса требует одного говорящего и покрытия не менее 80%. Слова разных голосов не объединяются. Смешанные интервалы остаются неопределёнными. Порог требует экспериментальной проверки.

LLM определяет роли по ограниченной выборке начала/конца реплик каждого голоса. Стартовая фраза — дополнительный сигнал. Факты извлекаются частями с передачей известных людей и фактов. После объединения проверяются ссылки, цитаты и группы противоречий. Ошибка структуры или источников останавливает этап.

Ограничения:

- Нейросетевые адаптеры, CPU/GPU и Windows ещё требуют реального прогона.
- LLM может пропускать факты, смешивать лиц, неверно разрешать местоимения и не находить противоречия. Проверка человеком обязательна.
- История известных фактов растёт с интервью. При нехватке контекста выдаётся явная ошибка; поддержка 60 минут ещё не доказана.
- Маркер неразборчивости основан на эвристике Whisper. VAD и лог-вероятности нуждаются в проверке на шумной речи.
- Запрет Python-сокетов не является системной изоляцией нативного кода. FFmpeg ограничен протоколами file/pipe. Приёмка требует испытания на Windows с отключённой сетью.
- Checkpoint PyTorch может содержать исполняемый pickle-код: использовать только доверенные веса с проверкой происхождения.
- Схема 1.0 проверяется строго; миграций пока нет. Сохранённая транскрипция допускает отдельный анализ, автоматического восстановления всех этапов нет.

Тестовый режим физически отделён от run: при отсутствии моделей настоящий запуск не подставляет заранее размеченные ответы.
