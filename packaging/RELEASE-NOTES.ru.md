Установщик Windows x64. Python отдельно не требуется.

1. Скачайте Biography-Setup-Windows-x64.exe и запустите его.
2. Откройте вкладку «Настройки» и подготовьте модели (первичная загрузка около 3 ГБ требует интернета).
3. После подготовки выберите аудио и нажмите «Начать обработку». Последующая обработка работает без интернета.

Для компьютера без сети заранее подготовьте папку данных на другом компьютере, перенесите её и выберите в настройках. Рекомендуется Windows 11 x64, 16 ГБ RAM и не менее 12 ГБ свободного места. Сборка использует CPU; ускорение RTX/CUDA не включено в проверенный профиль.

Приложен Windows-validation.zip: результаты фактического прогона EXE с локальными моделями, заблокированной исходящей сетью, русскими путями и M4A, а также снимок штатного окна Windows. SHA256SUMS.txt содержит контрольные суммы файлов выпуска.

Биография и транскрипции требуют проверки человеком. Распознавание может ошибаться в именах и названиях; неопределённые сведения и противоречия отмечаются. Этот предварительный выпуск проверен на синтетическом интервью и автоматических сценариях; статистическая полнота на реальных часовых интервью и работа GPU не подтверждены. Самоподпись кода отсутствует, поэтому Windows SmartScreen может попросить подтверждение запуска неизвестного издателя — не отключайте защиту Windows целиком.
